# QuoteTimeline

A Next.js (App Router) starter for a sourced quote + timeline site.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Notes

- Current content is **sample data** in `src/lib/sample-data.ts`.
- Before publishing, replace sample quotes with **verbatim, source-backed** entries.
- Add a clear disclaimer (already present in UI) and avoid implying endorsement.
